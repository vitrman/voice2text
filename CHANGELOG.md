# Изменения

## 0.3.3
- Комбинации из одних модификаторов (`ctrl+alt`, `alt+win`, `ctrl+shift` и т. п.):
  `parse_hotkey` принимает их с кодом клавиши 0, такие хоткеи ставит на перехват хуком.
- Хук срабатывает на нажатии модификатора, который завершает набор, и снова — после отпускания.
- Запись комбинации сохраняет такую пару без ошибки «неизвестная клавиша: alt».

## 0.3.2
- Запись комбинации вынесена в общий модуль `hotkey_capture.py`: до этого настройки
  импортировали `app` второй раз (в скрипте он `__main__`), состояние записи жило
  в двух копиях, и хук не видел нажатий — запись комбинации не работала вовсе.
- Если хук недоступен, запись откатывается на привязку Tk.

## 0.3.1
- Запись комбинации через клавиатурный хук: ловятся Win-комбинации (`win+d`, `alt+win`).
- Пока идёт запись, клавиши не уходят в окна, старые хоткеи не срабатывают.
- `alt+win` больше не вызывает ошибку разбора при сохранении.

## 0.3.0
- Диктовка по Alt+Win через перехват хуком.
