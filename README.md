# Voice2Text — офлайн-диктовка на GigaAM

[![check](https://github.com/vitrman/voice2text/actions/workflows/check.yml/badge.svg)](https://github.com/vitrman/voice2text/actions/workflows/check.yml)
[![Лицензия: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Локальное распознавание русской речи с микрофона и вставка текста в любое окно Windows.
Без облака, без подписки, без отправки звука наружу: модель GigaAM-v3 (Сбер) работает на CPU
прямо на вашем компьютере.

![Главное окно](docs/ui_main.png)

- **Push-to-talk и переключатель** — `Ctrl+Shift+Space` начинает/останавливает запись,
  режим «удерживать» пишет, пока клавиши зажаты.
- **Вставка в активное окно** — распознанный текст кладётся в буфер и вставляется `Ctrl+V`
  туда, где был курсор: Блокнот, браузер, мессенджер, 1С.
- **Пунктуация и регистр** — модели `v3_e2e_rnnt` (точнее) и `v3_e2e_ctc` (быстрее)
  отдают готовый текст, без ручной правки.
- **Автостоп по паузе** — настраивается или отключается совсем (тогда до кнопки «Стоп»).
- **Словарь замен** — «как слышится = Как надо» для имён, терминов, аббревиатур.
- **Трей, горячие клавиши, тёмная тема** — приложение живёт в фоне и не мешает.
- **Автозапуск** — галочка в настройках, приложение стартует в трее вместе с Windows.
- **Первый запуск по шагам** — модель, проверка микрофона, пробная фраза.

## Требования

- Windows 10/11 x64.
- Микрофон.
- ~1,1 ГБ на диске: 605 МБ программа + 430 МБ модель.
- Интернет нужен только один раз — скачать модель при первом запуске.

## Установка

### Готовый установщик

Установщик лежит **не в файлах репозитория**, а в разделе
[**Releases**](../../releases/latest) — он справа на странице репозитория, под описанием
(прямая ссылка: `https://github.com/<логин>/voice2text/releases`). Архив весит ~250 МБ,
поэтому в git его не кладут.

1. Открыть Releases → последний релиз → в блоке **Assets** скачать
   `Voice2Text-<версия>-installer.zip`, распаковать.
2. Запустить `setup.exe`. Права администратора не нужны: программа ставится в
   `%LOCALAPPDATA%\Programs\Voice2Text`, создаются ярлыки и запись в «Установка и удаление
   программ».
3. Первый запуск показывает визард: скачивание модели (~430 МБ) с прогрессом и отменой,
   проверка микрофона, пробная фраза.

Если в Releases пусто — релиз ещё не опубликован, тогда установщик можно собрать самому
(см. «Сборка exe и установщика») или работать из исходников.
Windows покажет SmartScreen (сборка подписана самоподписанным сертификатом):
«Подробнее» → «Выполнить в любом случае».

### Из исходников

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/). `ffmpeg` не требуется: аудио читается
через `soundfile`/`wave`.

```bat
install.cmd   :: создаёт .venv и ставит зависимости
run.cmd       :: запускает приложение из исходников
```

### Сборка exe и установщика

Всё одной командой (приложение закрыть):

```bat
release.cmd          :: exe + подпись + установщик в dist-installer
release.cmd trust    :: то же + сертификат в доверенные (SmartScreen молчит на этой машине)
push.cmd             :: git push origin main --tags
push.cmd pull        :: слить удалённые коммиты и запушить
push.cmd force       :: перезаписать удалённый main (если там ничего ценного)
release_github.cmd   :: опубликовать Release с архивом установщика
release_github.cmd -DryRun   :: только показать версию, тег и путь к архиву
```

`release_github.cmd` публикует через GitHub CLI, если он установлен и выполнен `gh auth login`;
иначе берёт personal access token с правом `repo` (или `Contents: Read and write` у
fine-grained токена). Токен можно сохранить один раз: он шифруется для вашей учётной
записи Windows в `%LOCALAPPDATA%\voice2text\github.token`, в репозиторий не попадает;
`release_github.cmd -Forget` удаляет сохранённый токен. Тег должен быть уже на GitHub —
сначала `push.cmd`.

По отдельности, если нужно только приложение или только установщик:

```bat
build.cmd                                          :: -> dist\Voice2Text
.venv\Scripts\python.exe installer\build_installer.py
                                                   :: -> dist-installer\Voice2Text-<версия>-installer.zip
```

Установщик не требует Inno Setup: `setup.exe` — обычное приложение на Python, а приложение
лежит рядом в `payload.zip`.

## Использование

| Действие | Как |
|---|---|
| Диктовка | `Ctrl+Shift+Space` (или кнопка «Записать», или пробел в окне приложения) |
| Показать окно | `Ctrl+Shift+W` |
| Остановить запись | повторное нажатие хоткея, кнопка «Стоп», пункт трея |
| Говорить следующую фразу | сразу, не дожидаясь распознавания — оно в очереди |
| Отменить распознавание | меню «Файл → Отменить распознавание» |
| Повторить последнюю запись | меню «Файл → Повторить последнюю запись» |
| Проверить микрофон | кнопка в настройках: живой уровень и вердикт |
| История диктовок | меню «Справка → Открыть историю» (`history.log`) |
| Настройки | правая панель главного окна, применяются сразу |
| Свернуть в трей | крестик окна или меню «Файл → Свернуть» |

Хоткей задаётся кнопкой «Записать» в панели настроек: нужна комбинация
`Ctrl/Shift/Alt + клавиша`. `Win` и одиночные клавиши не поддерживаются — Windows
забирает такие сочетания себе, а одиночная клавиша перестала бы печататься во всех программах.

## Как это работает

```
микрофон -> recorder.py (VAD, 16 кГц, WAV) -> jobs.py (очередь) -> asr_engine.py (GigaAM v3)
        -> postprocess.py -> history.py + буфер обмена + Ctrl+V в окно, активное до записи
```

| Файл | Роль |
|---|---|
| `app.py` | окно, трей, панель настроек, оверлей |
| `win32.py` | WinAPI: ввод, фокус, окна, хук, одиночный экземпляр |
| `jobs.py` | очередь распознавания: FIFO, отмена, глубина |
| `history.py` | история диктовок и последние три записи |
| `mic_check.py` | проверка микрофона: уровень и вердикт |
| `first_run.py` | визард первого запуска |
| `autostart.py` | автозапуск при входе в Windows |
| `theme.py` | палитра тёмной темы |
| `asr_engine.py` | загрузка модели, транскрибация, длинные записи кусками |
| `recorder.py` | запись в WAV, детектор речи, стоп по паузе/отпусканию |
| `model_fetch.py` | скачивание и проверка модели (докачка кусков) |
| `hotkeys.py`, `hotkey_capture.py` | разбор комбинаций, их состояние, запись комбинации хуком |
| `config.py`, `paths.py` | настройки и пути данных |
| `uninstall.py` | удаление программы и данных (`--uninstall`) |
| `clipboard.py` | системный буфер обмена через WinAPI |
| `postprocess.py` | замены, чистка текста |
| `update.py` | проверка и установка обновлений из GitHub Releases |
| `installer/` | установщик и его сборка |

Данные лежат рядом с исходниками (в exe — в `%LOCALAPPDATA%\voice2text`): `config.json`,
`.cache\gigaam` с моделью, `.cache\app.log` с журналом, `history.log` с диктовками и
`last\` с последними тремя записями.

## Обновление

Приложение само проверяет новый релиз на GitHub через 15 секунд после старта (ключ
`check_updates`, не чаще раза в 12 часов) и по меню **Справка → Проверить обновления…**.
Если версия новее — предлагает скачать `*-installer.zip` из Assets релиза. Скачивание идёт
в окне с прогрессом и кнопкой **Отмена**; уже скачанный архив сохраняется в
`%TEMP%\voice2text-update` и при повторной попытке не качается заново.

Установка идёт поверх текущей папки: exe на время распаковки переименовывается, приложение
закрывается, установщик получает `/WAITPID=<pid>` и сам ждёт выхода процесса, ставит новую
версию и запускает её снова. Пакетного файла-помощника больше нет — раньше он ломался на
кириллице в путях `%TEMP%`/`%LOCALAPPDATA%`. Конфиг, модель и журналы лежат в `%LOCALAPPDATA%`
и не затрагиваются.

Скачанный архив проверяется по sha256 (поле `digest` релиза или файл `*.zip.sha256`) и по
целостности zip; несовпадение — понятное сообщение вместо «не установилось». Кэш в
`%TEMP%\voice2text-update` убирается при следующем запуске, остатки `*.old` — тоже.
Если установка не удалась, exe возвращается на место, а причина пишется в
`%TEMP%\voice2text-update\install.log`.

Удаление — через «Установка и удаление программ»: `Voice2Text.exe --uninstall` спрашивает
подтверждение и удаляет программу вместе с настройками, историей, журналами и моделью.

Репозиторий для проверки задаётся ключом `github_repo` (по умолчанию
`vitrman/voice2text`). Обновление работает только для установленной версии; при запуске
из исходников пункт меню сообщает об этом.

## Настройки

`config.json`: `model` (`v3_e2e_rnnt`/`v3_e2e_ctc`), `device` (`{"name": …, "hostapi": …}`
или `null` — микрофон хранится по имени, а не по номеру), `hotkey`, `show_hotkey`,
`hotkey_mode` (`toggle`/`hold`), `silence_ms`, `auto_stop`, `chunk_seconds`,
`autopaste`, `start_minimized`, `replacements`, `check_updates`, `github_repo`.

Длительность записи не настраивается: пишем в файл, пока не остановят, со страховкой
30 минут.

Настройки пишутся атомарно и с резервной копией `config.bak`: если основной файл повреждён,
он восстанавливается из копии, а ошибка попадает в журнал.

## Если что-то не работает

- **Текст не вставляется в другое окно** — целевое окно запущено от администратора, а
  приложение нет: Windows (UIPI) не даёт синтетическому вводу попасть в такое окно.
  Запустите приложение от администратора тоже.
- **Хоткей не срабатывает** — комбинацию занял другой процесс. Поле в настройках получит
  оранжевую рамку, подсказка скажет, что реально работает (запасная комбинация), а раз в
  минуту приложение пробует вернуть вашу. Занятость проверяется и при записи комбинации.
- **Запись не останавливается по отпусканию** — с 0.8.6.1 режим «удерживать» работает с
  любым хоткеем; обновитесь, если версия ниже.
- **Модель не скачалась** — проверьте журнал `.cache\app.log`; недокачанные куски
  докачиваются при следующем запуске, а не с нуля.
- **Нет текста, тишина** — нажмите «Проверить микрофон» в настройках: окно покажет живой
  уровень и вердикт («слышно хорошо / тихо / нет сигнала / устройство занято»). После ошибки
  записи приложение само предлагает эту проверку.
- **Пропало слово в середине** — микрофон не успевал отдавать звук (переполнение буфера).
  В журнале будет строка `переполнение аудиобуфера: потеряно N мс`, в статусе — предупреждение.
  Закройте тяжёлые программы: распознавание уже оставляет одно ядро системе.
- **SmartScreen ругается** — сертификат самоподписанный, для своей машины можно выполнить
  `trust.cmd` от имени администратора.

Полный журнал: `.cache\app.log` (в exe — `%LOCALAPPDATA%\voice2text\.cache\app.log`).
Меню «Справка → Диагностика» копирует отчёт в буфер обмена.

## Разработка

Правила версий и коммитов — в [`AGENTS.md`](AGENTS.md) и [`CONTRIBUTING.md`](CONTRIBUTING.md),
история изменений — [`CHANGELOG.md`](CHANGELOG.md). Версия `MAJOR.МИНОР.ПАТЧ.1` пишется
в заголовке окна.

```bat
.venv\Scripts\python.exe tools\ci_check.py               :: версия, CHANGELOG, разбор хоткеев
.venv\Scripts\python.exe tests\test_config_and_hotkeys.py :: настройки и состояние хоткеев
.venv\Scripts\python.exe tests\test_update_flow.py        :: обновление: кэш, PID, sha256, установка
.venv\Scripts\python.exe tests\test_ptt_stop.py           :: стоп по отпусканию любого хоткея
.venv\Scripts\python.exe tests\test_queue_and_history.py  :: очередь, история, запись в файл
.venv\Scripts\python.exe tests\test_startup.py            :: автозапуск и вердикты микрофона
.venv\Scripts\python.exe smoke_test.py            :: сквозная проверка на тестовом WAV
```
