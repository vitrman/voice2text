# Как участвовать

Спасибо за интерес к проекту. Ниже — короткие правила, чтобы правки было легко проверять.

## Окружение разработчика

```bat
install.cmd                 :: .venv + зависимости
run.cmd                     :: запуск из исходников
```

Нужны Windows 10/11 x64, Python 3.12, [uv](https://docs.astral.sh/uv/) и `ffmpeg` в `PATH`.
Модель скачивается автоматически при первом запуске в `.cache\gigaam`.

## Перед правкой

- Для новой функции — короткое описание в задаче: сценарий, ожидаемое поведение, как проверить.
- Меняйте один смысловой блок за раз: так проще откатить, если подход не подошёл.
- Не добавляйте зависимости без необходимости: каждая увеличивает установщик.

## Что проверить

1. `python -m compileall -q app.py asr_engine.py recorder.py settings_ui.py` — синтаксис.
2. `python tests\test_hotkey.py` — разбор и регистрация хоткеев.
3. `python smoke_test.py` — сквозная проверка распознавания на тестовом WAV.
4. Ручная проверка сценария: диктовка в Блокнот, вставка в другое окно, «Стоп»,
   смена хоткея в настройках.

GUI-проверку в среде без экрана делать не нужно — достаточно сказать в описании правки,
что именно проверялось вручную.

## Код

- Python 3.12, только стандартная библиотека + зависимости из `requirements.txt`.
- Комментарии и сообщения пользователю — по-русски, идентификаторы — по-английски.
- WinAPI вызывается через `ctypes`; не забывайте `argtypes`/`restype` для дескрипторов окон.
- Ничего не пишите вне каталога данных (`paths.DATA`): приложение работает и без прав администратора.

## Версии и коммиты

- Версия живёт в `version.py`, формат `MAJOR.МИНОР.ПАТЧ.1` (четвёртое число всегда 1).
- Исправление или рефакторинг — `ПАТЧ+1`, новая функция — `МИНОР+1` (`ПАТЧ=0`),
  несовместимое изменение — `MAJOR+1`.
- В одном коммите: код + `version.py` + запись в `CHANGELOG.md`.
- Сообщение коммита: `тип: суть (версия)`, например `fix: вставка в чужое окно (0.7.1.1)`.
- Релиз помечается тегом `v<версия>`.

## Pull request

- Опишите, что и зачем изменено, и как это проверено.
- Если меняется поведение — обновите README (разделы «Использование»/«Если что-то не работает»).
- Если добавляете зависимость — строку в `requirements.txt` и `THIRD_PARTY.md`.
- Скриншот для правок интерфейса обязателен.
